## Criterios de Aceptación y Estado

| Criterio de Aceptación | Estado | Evidencia de Cumplimiento |
| :--- | :---: | :--- |
| **Puedo iniciar un descanso** | Cumplido | Botón `Iniciar descanso` (o `Reanudar`) disponible en cada ejercicio de la sesión. Inicia la cuenta regresiva segundo a segundo. |
| **Puedo detener/pausar un descanso** | Cumplido | Botones `Pausar` (congela el contador conservando los segundos restantes) y `Detener` (para y resetea). |
| **Veo el tiempo restante** | Cumplido | Contador visible en tiempo real con doble formato (MM:SS y segundos, ej. `01:30 (90 s)`), con roles de accesibilidad `role="timer"` y `aria-live="polite"`. |
| **Tomar como valor inicial el descanso configurado cuando exista** | Cumplido | Si el ejercicio tiene descanso configurado (`item.parameters.restSeconds`), arranca exactamente con dicho valor (ej. Sentadilla 90 s, Remo 60 s). Si no tiene descanso configurado, utiliza 60 s como valor por defecto. |
| **Reinicio del temporizador** | Cumplido | Botón `Reiniciar` disponible en cualquier momento para restablecer el temporizador a su descanso inicial configurado. |

## Tareas Implementadas

1. **Componente de temporizador (`web/src/routines/RestTimer.tsx`)**:
   - Ciclo de vida completo del descanso: estados `idle` (listo), `running` (en curso), `paused` (en pausa) y `finished` (finalizado).
   - Control de tiempo basado en timestamps (`targetEndTime = Date.now() + seconds * 1000`) para evitar desincronización por throttling del navegador.
   - Acciones de control: `Iniciar descanso`, `Pausar`, `Reanudar`, `Detener`, `Reiniciar`.
   - Ajustes rápidos en vivo (`+15 s`, `-15 s`, `+30 s`) para adaptarse a las necesidades del entrenamiento.
   - Aviso visual destacado (`¡Descanso completado! Preparado para la siguiente serie`) y señal acústica sintética opcional mediante Web Audio API al llegar a 0.

2. **Integración en la sesión de entrenamiento (`web/src/routines/TrainingSession.tsx`)**:
   - Cada ejercicio listado en la sesión guiada dispone de su propio temporizador contextualizado con el nombre del ejercicio y sus parámetros configurados.
   - Conserva íntegro el contrato visual y de datos previo (`Descanso: X s`, `RIR: X`, series y repeticiones).

3. **Estilos y Accesibilidad (`web/src/routines/rest-timer.css`)**:
   - Cumplimiento WCAG 2.1 AA: botones con altura táctil mínima de 44px (`min-height: 44px`), navegación por teclado fluida (Tab / Enter / Espacio) y foco visible de alto contraste.
   - Diseño adaptable (*responsive*) probado a 320px, 390px, 768px y 1440px sin desbordamiento horizontal.
   - Etiquetas accesibles (`aria-label`, `role="timer"`, `role="status"`).

4. **Suite de pruebas de extremo a extremo (`tests/e2e/p4-rest-timer.spec.ts`)**:
   - Prueba 1: Comprobación de valor inicial configurado (90 s para Sentadilla, 60 s para Remo).
   - Prueba 2: Ciclo de vida interactivo (inicio, pausa, congelación del contador, reanudación, reinicio, detención).
   - Prueba 3: Ajustes rápidos de tiempo (+30 s, -15 s).
   - Prueba 4: Finalización de cuenta atrás, cambio de estado a `¡Finalizado!` y banner accesible.
   - Prueba 5: Verificación de accesibilidad móvil (sin scroll horizontal a 320px y 390px) y tamaño táctil de 44px.
